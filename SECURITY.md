# Security policy

## Supported versions

Only the latest tagged release is supported. Until the first release, `main` is development-only and **must not** be used for unattended production firmware builds.

## Reporting a vulnerability

Do not open a public issue for a suspected credential leak, pairing weakness, or unsafe BLE behaviour. Use GitHub's private security-advisory reporting for this repository, or contact the maintainer privately through the GitHub profile.

Never include Wi-Fi credentials, API/OTA keys, pairing codes, MAC addresses, IP addresses, or packet captures containing identifying information in a report.
